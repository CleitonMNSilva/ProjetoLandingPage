# CS Security — Landing Page

**Autor:** Cleiton Marcelo Nunes da Silva  
**Curso:** Análise e Desenvolvimento de Sistemas (ADS) — 1ª fase  
**Projeto online:** https://cleitonmnsilva.github.io/ProjetoWeb/

## 1. Sobre o projeto

Esta landing page apresenta a **CS Security**, com foco em duas áreas complementares: **cibersegurança** e **segurança patrimonial**. A proposta é comunicar os serviços de forma clara, com uma identidade visual tecnológica e caminhos diretos para contato.

Este projeto foi minha primeira experiência desenvolvendo uma landing page. A ideia nasceu da minha vivência profissional: atualmente trabalho na área de segurança patrimonial na empresa **Segurpro Vigilância S/A**. Essa experiência despertou meu interesse em unir a proteção física à segurança digital e faz parte do meu sonho de criar minha própria empresa de cibersegurança.

## 2. Principais destaques

- Apresentação principal com chamada para contato.
- Seção de especialidades com dois serviços: cibersegurança e segurança patrimonial.
- Links de contato por WhatsApp e e-mail.
- Formulário com campos para nome, empresa e mensagem, que prepara o contato via WhatsApp.
- Botão flutuante de WhatsApp para facilitar o acesso ao atendimento.
- Layout responsivo com ajustes para telas menores.
- Publicação online pelo GitHub Pages.

### Organização da página

1. **Cabeçalho:** identificação CS Security e acesso ao WhatsApp.
2. **Apresentação principal:** mensagem de segurança de alta performance e botão para falar com especialista.
3. **Especialidades:** cartões de cibersegurança e segurança patrimonial.
4. **Contato:** WhatsApp, e-mail, formulário e rodapé.

## 4. Tecnologias e recursos utilizados

- **HTML5:** estrutura do conteúdo.
- **Tailwind CSS (via CDN):** utilitários de layout e estilização.
- **CSS:** efeitos visuais próprios e ajuste de apresentação em telas menores.
- **JavaScript:** inicialização dos ícones e encaminhamento dos dados do formulário para uma conversa no WhatsApp.
- **Lucide:** biblioteca de ícones.
- **Google Fonts:** fontes Inter e JetBrains Mono.
- **GitHub Pages:** publicação da página na internet.

O projeto também utiliza gradientes, transparências, cartões com efeito de vidro (*glassmorphism*), sombras e transições de interação.

## 6. Imagem de fundo

O CSS utiliza o arquivo local **`img/foto.png`** como imagem de fundo, combinado com gradientes escuros e realces em vermelho, azul-ciano e dourado. A imagem é configurada para cobrir a área disponível e ficar centralizada.

**Origem da imagem:** o código-fonte informa apenas o caminho local `img/foto.png`; não identifica o site de origem, autor ou licença. Esses dados precisam ser verificados no arquivo original ou no histórico de obtenção da imagem antes de atribuir autoria ou confirmar permissão de uso.

## 7. Pontos fortes e conclusão

- Reúne segurança física e digital em uma única apresentação.
- Oferece caminhos de contato em diferentes partes da página.
- Encaminha o formulário para o WhatsApp sem exigir um sistema de backend próprio.
- Usa uma identidade visual consistente com o tema de tecnologia e segurança.
- Demonstra a aplicação prática de HTML, CSS, bibliotecas externas e JavaScript.
- Está disponível publicamente para consulta e apresentação em portfólio.

Ele conecta minha experiência profissional em segurança patrimonial ao meu objetivo de empreender no setor de cibersegurança, além de representar uma oportunidade de desenvolver e demonstrar conhecimentos de desenvolvimento web.
